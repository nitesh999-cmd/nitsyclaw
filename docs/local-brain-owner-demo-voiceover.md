# Local Brain owner demo voiceover

Local Brain is a private personal assistant running here on this laptop. The Qwen model runs through Ollama in local-only mode, so this demonstration has no cloud AI fallback.

It remembers useful personal context. Here, it recalls that peppermint tea is the current preference, and it uses saved evidence to keep today's focus grounded.

It also learns corrections. The old preference has been retired, so only the corrected memory is used.

Privacy boundaries are checked before memory reaches the assistant. Another owner's memory stays private, and a hidden instruction stored inside memory is rejected.

When a request could act outside the laptop, Local Brain stops. This synthetic WhatsApp action is waiting for approval, and the action-call count remains zero.

Finally, this sentence is a real response from Qwen, routed locally through Ollama.

Local Brain: remembers privately, acts carefully, runs locally.
